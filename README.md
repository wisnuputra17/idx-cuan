# IDX Cuan — Analisa Teknikal Saham IDX Otomatis

Website statis yang menampilkan analisa teknikal saham IDX paling likuid, update harian otomatis.

- **Sumber data:** Yahoo Finance (publik, legal)
- **Indikator:** MA20/MA50, RSI14, Donchian 10-hari, Volume, ATR14
- **Output:** skor komposit, verdict (bullish/bearish/netral), level entry/SL/TP
- **Generator:** `build_site.py` → `public/`

Bukan nasihat keuangan. DYOR.
